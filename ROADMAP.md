# Roadmap: Hunt KD Tracker

Здесь собран глобальный план развития нашего калькулятора. Мы будем отмечать галочками выполненные задачи по мере продвижения.

## Этап 1: Интеграция с трансляцией
- [x] **1. Создать виджет для OBS (`obs.html`)**
  - Облегченная версия калькулятора без фона и меню.
  - Прозрачный фон для наложения поверх игры.
  - Подключение к Supabase Realtime для моментального обновления цифр на стриме.

## Этап 2: Визуализация данных
- [ ] **[ВЫСОКИЙ ПРИОРИТЕТ] Детальная поматчевая история в `history.html`**
  - Добавить попап, открывающийся при клике/наведении на завершенную сессию.
  - Выводить внутри попапа таблицу со всеми матчами этой сессии (как в редакторе).
  - Рисовать внутри попапа мини-график динамики KD сессии (как на главном экране).
- [ ] **2. Заполнить графики (`charts.html`)**
  - Оживить страницу графиков.
  - Сделать красивую отрисовку динамики KD и статистики на основе истории из базы данных.

## Этап 3: Интерактив и геймификация
- [ ] **3. Добавить персонажей на начальный попап**
  - Анимированное появление персонажей (Манус, Файфилд, Билли Херрингтон) при старте стрима/сессии.
- [ ] **4. Добавить фразы и персонажей на конечный попап**
  - Логика подведения итогов дня.
  - Уникальные комментарии персонажей, зависящие от успехов (KD дня, закрыт ли дефицит и т.д.).
- [ ] **5. Попробовать добавить звуки и видео**
  - Озвучка попапов и важных событий (старт, стоп, рекордный матч).
  - Интеграция видео-вставок при достижении особых результатов.

## Этап 4: Креатив
- [ ] **6. Подумать над пасхалками и приколами в Ханте**
  - Секретные анимации, редкие фразы или скрытые функции для самых внимательных зрителей.

## Этап 5: Развитие и портфолио
- [ ] **7. Добавить кнопку "О разработчике"**
  - Разместить большую, заметную кнопку рядом с таймером.
  - При клике должен открываться стилизованный попап.
  - Текст внутри: "Есть интересная задача? Напиши, обсудим."
  - Две кнопки для связи: Telegram и Почта.
  - *Важно: внедрять только после того, как весь основной функционал будет работать идеально и без багов.*

## Этап 6: Трекинг эффективности оружия (Лодауты)
- [ ] **8. Глубокая статистика по пушкам**
  - Возможность отмечать лодаут на всю сессию (через текстовое поле, а в будущем — через выпадающий список со всем арсеналом игры).
  - Чекбокс при добавлении каждого отдельного матча: "Сыграно на другом лодауте" (чтобы исключить "левые" матчи из статистики пушки).
  - В редакторе матчей добавить возможность указать, с каким именно лодаутом сыгран конкретный матч.
  - Построение глобального графика зависимости KD от выбранного оружия.
