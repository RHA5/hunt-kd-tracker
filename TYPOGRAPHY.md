# Спецификация типографики проекта Hunt Tracker

Этот документ является строгим законом оформления для всех веб-страниц проекта (включая `preview.htm`, `history.html`, `charts.html`). ИИ-агент обязан сверяться с ним при любых изменениях дизайна.

## 1. Подключение шрифтов (Google Fonts в <head>)
```html
<link href="https://fonts.googleapis.com/css2?family=Courier+Prime:ital,wght@0,400;0,700;1,400;1,700&family=EB+Garamond:ital,wght@0,400..800;1,400..800&family=Forum&family=Special+Elite&display=swap" rel="stylesheet">
2. Спецификация элементов
Верхнее меню («АНАЛИТИКА» и др.): шрифт Forum, text-[13px], UPPERCASE, tracking-[2px], цвет #ffffff (активный) / rgba(229, 226, 225, 0.5) (в покое).
Главные кнопки («НАЧАТЬ ОХОТУ» / «ЗАПИСАТЬ МАТЧ»): шрифт Forum, text-[12px] / text-[11px], UPPERCASE, tracking-[2px], цвет #d9c39c.
Таймер («00:00:00»): моноширинный шрифт Courier Prime, text-2xl, при активности сессии — цвет #ffb4ab, в покое — #8e9192.
Заголовки всех карточек: шрифт Forum, text-sm / text-base, UPPERCASE, цвет #dac493, tracking-[2px] (над колбой — tracking-[4px]). Под ними — градиентная разделительная нить.
Динамика КД дня («+0.00000 KD»): шрифт Special Elite, text-2xl, цвет зеленый (#4ade80) при плюсе, красный (#ffb4ab) при минусе.
Стандартные строки (Боковые колонки 1 и 3):
Подписи (слева): шрифт EB Garamond, text-[15px], регистр как в предложениях (Sentence Case), цвет #c4c7c7.
Значения (справа): шрифт Special Elite, text-[17px], font-bold, цвет #e5e2e1.
Приоритетные строки (Центральная колонка «Статистика дня»):
Подписи (слева): шрифт EB Garamond, text-[17px], регистр как в предложениях (Sentence Case), цвет #c4c7c7.
Значения (справа): шрифт Special Elite, text-[19px], font-bold, цвет #e5e2e1.
3. Правила верстки и чистки данных
Каждая строка во всех таблицах статистики должна иметь одинаковый вертикальный отступ и только один приглушенный разделитель внизу (border-bottom 1px solid #35312c).
Никакого вертикального растягивания (убрать justify-around / flex-grow). Если в карточке мало строк, снизу должно оставаться свободное темное пространство.
В правой колонке значений должны быть только чистые цифры, слова "матчей", "дня" переносятся в левую колонку к подписям!
